= Exigences de port pour NetApp Data Migrator
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Vous devez vous assurer que certains ports TCP sont ouverts pour permettre la communication entre les machines virtuelles (VM) du plan de contrôle et les VM de travail dans NetApp Data Migrator.



[[control-plane-ports]]
== ports du plan de contrôle

[cols="1,1,1,1a"]
|===
| Service | port TCP | Depuis | À 


| Temporel | 7233 ou 7234, 8080 | Travailleurs et clients (navigateur ou tout client externe)  a| 
Plan de contrôle



| Redis | 6379 | Travailleurs et clients (navigateur ou tout client externe)  a| 
Plan de contrôle



| Application NDM | 443 | Travailleurs et clients (navigateur ou tout client externe)  a| 
Plan de contrôle



| Grafana | 3000 | Navigateur  a| 
Plan de contrôle



| Console de gestion Isilon | 443, 8080 | Plan de contrôle  a| 
Console de gestion Isilon



| Sortie vers le stockage | 2049 | Plan de contrôle  a| 
Serveurs NFS

*Remarque* : Incluez le port TCP ou UDP 111 si vous avez besoin du service portmapper pour les Remote Procedure Calls.



| Sortie vers le stockage | 445 | Plan de contrôle  a| 
Serveurs SMB

|===
